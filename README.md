# CryptoFlow · 加密流量分析与异常检测工具

## 解决的问题

现代网络流量中 **90% 以上是加密流量**（TLS/SSL），传统基于端口和载荷的流量分析方法失效。本工具解决以下实际问题：

1. **加密流量分类**：识别加密流量的应用类型（浏览、视频、流媒体、聊天、文件传输、邮件等）
2. **异常检测**：检测加密流量中的异常行为（可能的恶意软件、数据泄露、隧道攻击）
3. **协议指纹识别**：通过 TLS 握手特征识别加密协议和实现库

## 技术原理

### 特征工程
从 PCAP/PCAPNG 文件中提取 **80+ 维特征**：
- **统计特征**：包长度分布（均值、方差、分位数）、包间隔时间统计
- **TLS 握手特征**：密码套件、TLS 版本、扩展列表、证书长度
- **流特征**：上下行比例、流持续时间、包数量
- **熵特征**：载荷熵值（区分加密与非加密流量）

### 机器学习模型
- **随机森林**：用于流量分类（准确率 ~95%）
- **孤立森林**：用于异常检测
- **特征重要性分析**：识别最具区分力的特征

## 使用方法

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 生成示例数据（无真实 PCAP 时）
```bash
python main.py --generate
```

### 3. 训练模型
```bash
python main.py --train
```

### 4. 分析 PCAP 文件
```bash
python main.py --pcap traffic.pcap
```

### 5. 实时捕获分析
```bash
python main.py --live --interface eth0 --count 100
```

### 6. 完整流程
```bash
python main.py --all
```

## 实际应用场景

1. **企业网络安全**：监控内部网络加密流量，检测异常行为
2. **流量审计**：对加密流量进行分类统计，了解网络使用情况
3. **恶意软件检测**：检测加密 C2 通信、数据外泄
4. **协议合规**：验证 TLS 配置是否符合安全标准
